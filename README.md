## Ben Kimim?

Karabük Üniversitesi Bilgisayar Mühendisliği bölümünden **3 yılda mezun oldum**. Java ve Spring Boot ekosisteminde; sürdürülebilir, ölçeklenebilir ve üretim ortamına hazır backend sistemleri geliştiriyorum.

Kod yazmanın yanında iş problemlerini doğru anlamaya, sade mimariler kurmaya ve fikirleri çalışan ürünlere dönüştürmeye önem veriyorum.

- 🔭 **Şu anda:** Java & Spring Boot ile backend sistemleri geliştiriyorum
- 🧩 **İlgilendiğim alanlar:** Microservices, event-driven architecture ve distributed systems
- 🌱 **Öğreniyorum:** Kubernetes, Cloud Native Java ve ileri seviye Kafka
- ⚙️ **Yaklaşımım:** Clean code, doğru domain modelleme ve gözlemlenebilir sistemler
- 🎯 **Hedefim:** Yüksek trafikte güvenilir çalışan ürünler geliştirmek
